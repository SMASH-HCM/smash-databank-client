SMASH-HCM Databank Client 0.12.0

- The distribution, command and portable executable are now `smash-hcm-databank-client`. Application code moved to `src/smash_hcm_databank_client/`; historical experiment scripts moved to its `legacy/` subpackage. Existing saved profile/vault settings remain usable.
- Rewritten collaborator README, installation/download instructions, custom clinical-variable JSON, train/test examples, explicit history/transform explanations, event-stream caveats, and an indexing/landmarking guide. The databank paper link remains TODO until supplied.
- Friendly feature-set labels/identifiers, with old preset identifiers retained as aliases. New `esc-risk` input-review set includes seven candidate source concepts plus recorded baseline age. It does not calculate a validated clinical risk score.
- Tested optional ECG tutorial helper for guarded extraction and reviewed person/date/path linkage to patient-disjoint clinical splits. It needs an explicit asset index; automatic curator linkage, waveform decoding and training remain outside the client.
- Native folder builds and wheel/source releases use the new name; installed-wheel checks verify the old console command is absent. Unit/workflow tests use temporary synthetic data, without developer drive paths.

For Python upgrades, uninstall the old `omop-exporter` distribution in that environment before installing the new wheel. Replace `python -m omop_exporter` with `python -m smash_hcm_databank_client`. Historical tools are invoked with `python -m smash_hcm_databank_client.legacy.<module>`.

Database/asset releases and their clinical limitations are independent of this application version. Baseline exports still require complete valid anchors; no missing dates, outcome labels or negatives are inferred.
